# Isolated Hastings–Powell system

This directory contains the numerical analysis used to characterize the
dynamics of the isolated Hastings–Powell (HP) system and to establish the
chaotic working points used in the subsequent coupled-system analysis.

The calculations are organized in two consecutive parts: characterization of
the relevant parameter regions and detailed analysis of the selected isolated
dynamics.

## `01_chaos_characterization`

This part examines how the isolated HP dynamics change with the mortality
parameter $d_1$ and identifies suitable chaotic working points.

The numerical analysis is divided among three notebooks:

- **`hp_global_d1_scan.ipynb`**  
  Global exploration of the $d_1$ parameter range, including bifurcation
  information, Lyapunov-exponent estimates, and continuation calculations.

- **`hp_fine_d1_scans.ipynb`**  
  Higher-resolution scans of selected parameter intervals identified from the
  global exploration.

- **`hp_working_points_checks.ipynb`**  
  Additional numerical checks at the selected working points, including
  convergence tests, block-based Lyapunov estimates, and diagnostics based on
  local maxima and return maps.

The `data/` directory contains the numerical outputs generated by these
calculations, while `figures/` contains the corresponding bifurcation diagrams,
fine scans, continuation comparisons, empirical distributions of maxima, and
return maps.

## `02_isolated_dynamics`

This part studies the isolated dynamics at the selected chaotic working points

```math
d_1=0.38
\qquad\text{and}\qquad
d_1=0.40.
```

The analysis is contained in

```text
hp_isolated_dynamics.ipynb
```

and includes:

- population time series;
- three-dimensional attractors;
- two-dimensional phase-space projections;
- running Lyapunov exponents;
- block-based Lyapunov estimates and uncertainty analysis;
- sensitivity to nearby initial conditions;
- direct comparisons between the two working points.

The numerical results are stored in `data/`, and the corresponding static
figures and dynamical visualizations are stored in `figures/`.

## Suggested reading order

The notebooks are intended to be followed in the numerical order of the
analysis:

```text
hp_global_d1_scan.ipynb
        ↓
hp_fine_d1_scans.ipynb
        ↓
hp_working_points_checks.ipynb
        ↓
hp_isolated_dynamics.ipynb
```

The first three establish where the working points are located in parameter
space and test their numerical behavior. The final notebook then examines the
resulting chaotic dynamics in detail.

## Numerical routines

Each analysis directory currently contains a local copy of `hp_core.py`, which
provides the Hastings–Powell equations, Jacobian, numerical integration
routines, and Lyapunov-exponent utilities used by the notebooks in this stage.
